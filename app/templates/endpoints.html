Try the write endpoints with curl

The JSON APIs do not need a CSRF token. Run these from a terminal.

# Create a student
curl -i -X POST {{ base_url }}api/v1/students \
  -H "Content-Type: application/json" \
  -d '{"roll_number":"CSA2026099","name":"Test Student","email":"test@example.edu","course":"Cloud Computing","year":2}'

# Update it (replace 26 with the id returned above)
curl -i -X PUT {{ base_url }}api/v1/students/26 \
  -H "Content-Type: application/json" \
  -d '{"roll_number":"CSA2026099","name":"Test Student","email":"test@example.edu","course":"DevOps Engineering","year":3}'

# Delete it
curl -i -X DELETE {{ base_url }}api/v1/students/26

# Validation error example (returns 400 with field messages)
curl -i -X POST {{ base_url }}api/v1/students -H "Content-Type: application/json" -d '{"name":"X"}'
